# @dam/api

Backend REST API for the DAM platform.

Built with Express and TypeScript. It handles user authentication, asset management, and analytics.

## Setup

1. Copy `.env.sample` to `.env` and fill in the values.
2. Run `pnpm install`.
3. Run `pnpm run dev` to start the development server.

## API Documentation

Swagger API documentation is available at `/api-docs` when running the server.
