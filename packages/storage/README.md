# @dam/storage

Storage package for the DAM platform.

This package provides an abstraction over MinIO/S3 for uploading, downloading, and managing digital assets.

## Configuration

Requires MinIO credentials and endpoint configuration via environment variables:

- `MINIO_ENDPOINT`
- `MINIO_PORT`
- `MINIO_ACCESS_KEY`
- `MINIO_SECRET_KEY`
- `MINIO_BUCKET`
